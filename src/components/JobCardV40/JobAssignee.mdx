# JobAssignee

Kapsle s iniciály lidí zapojených do náboru v hlavičce karty. Po najetí se otevře hover karta se jmény a rolemi.

```tsx
import { JobAssignee } from '@teamio/starter/components/JobCardV40'

<JobAssignee
  owner="Petra Nováková"
  hiringManagers={['Lukáš Procházka']}
  colleagues={[{ name: 'Eva Dvořáková', role: 'HR' }]}
  onInviteMore={() => …}
/>
```

## Pravidla

- Náborář (`owner`) je vždy první, role `Náborář`.
- Další osoby nemusí být jen hiring manageři. Pořadí za nimi: `hiringManagers` (role `Hiring manager`), pak `colleagues`
  (např. HR kolegové) s vlastní rolí: `{ name: 'Eva Dvořáková', role: 'HR' }`. Bez `role` je výchozí `Hiring manager`.
- Na kapsli jsou vidět iniciály maximálně 2 lidí, zbytek se sbalí do `+N`.
- Tlačítko „Upravit zapojení“ v hover kartě se zobrazí jen tehdy, když je předán `onInviteMore`.
