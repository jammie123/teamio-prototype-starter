# AdvertisementHeader

Hlavička inzerce: datum od–do a prioritní upoutávka (Končí brzy, Expirováno). Vykresluje ji `AdvertisementWidget`,
hodnoty (`tone`, `label`, `dateInfo`, `highlighted`) počítá `buildAdvertisementModel`.

```tsx
import { AdvertisementHeader } from '@teamio/starter/components/JobCardV40'

<AdvertisementHeader tone="warning" label="Končí za 3 dny" dateInfo="1. 9. – 30. 9. 2026" highlighted />
```

## Tóny

| `tone` | Použití | Barva labelu |
| --- | --- | --- |
| `success` | Běží (label se nezobrazuje, jen datum) | zelená |
| `warning` | Končí brzy, Expirováno před N dny | oranžová, tučné |
| `ended` | Expirováno, Ukončené vystavování | šedá |
| `neutral` | Zatím nevystavený inzerát | šedá |

`highlighted` přidá tónované pozadí, větší text a ikonu hodin. Používá se u Končí brzy a u expirace do 7 dní.
`label` bez `dateInfo` i naopak jsou platné kombinace.

## Texty podle stavu

| Stav | `label` | Pozn. |
| --- | --- | --- |
| Běží | – | jen `dateInfo` |
| Končí brzy | `Končí za N dní`, `Končí dnes` | `highlighted` |
| Expirováno do 7 dní | `Expirováno před N dny`, `Expirováno dnes` | `highlighted` |
| Expirováno více než 7 dní | `Expirováno` | šedá |
| Ukončené vystavování | `Ukončené vystavování` | šedá |
| Bez inzerce | `Zatím nevystavený inzerát` | neutrální |
